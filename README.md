# openpeon-duke-nukem

Duke Nukem sound pack for [peon-ping](https://peonping.com): one-liners by Jon St. John as terminal notifications.

## Install

```
# local test (before it is on GitHub):
cp -r . ~/.claude/hooks/peon-ping/packs/duke_nukem_jsj
peon packs use duke_nukem_jsj
```

## Sounds (135 total across 7 categories)

| Category | Sounds | Examples |
|---|---|---|
| `session.start` | 20 | 'Hail to the King, Baby', "I'm Back!" |

| `task.complete` | 19 | 'Too Easy!', "That's How We Do It!" |
| `task.error` | 22 | 'Damn It to Hell', 'Oh, COME ON!' |
| `input.required` | 19 | "Hey, Genius! What're You Waitin' for", "What's the Hold Up" |

| `user.spam` | 20 | 'Shut UP!', 'Sit Down and Shut Up!' |

All clips are trimmed, loudness-normalised (-16 LUFS), mono 44.1 kHz MP3. Many lines are **explicit**.

## Source / origin

The clips come from the fan-made
[Duke Nukem - Vocal Collection](https://archive.org/details/DukeNukemVocalCollection) on the Internet Archive:
1,858 voice lines from the Duke Nukem game series, which its uploader says were gathered or extracted from the games
(Duke Nukem 3D and later titles). The collection ships without any license or rights statement.

This pack is a curated selection of that collection: only short, speech-only lines, de-duplicated (one take per
line), trimmed and loudness-normalised. Nothing was re-recorded or altered otherwise.
